# ScanPPP

Сканирование локальной сети: компьютеры, IP-телефоны и принтеры в одном интерфейсе.

Рассчитано на одну сеть без VLAN — сканер видит только свой L2-сегмент.

## Требования

| Компонент | Версия | Нужен для |
| --- | --- | --- |
| Windows | 7+ | определение компьютеров и MAC (`ping`, `arp`, `nbtstat`) |
| XAMPP (Apache + PHP) | PHP 8.1+ | всё приложение |
| Расширение PHP `snmp` | — | вкладка «Принтеры» (в XAMPP включено) |
| Python | 3.x в `PATH` | вкладка «Компьютеры» |

`snmp` проверяется командой `php -m` в консоли XAMPP. Python — командой `python --version`.

## Запуск

1. Скопировать папку `ScanPPP` в `C:\xampp\htdocs\`.
2. Запустить **Apache** в панели XAMPP.
3. Открыть `http://localhost/ScanPPP/`.

При первом запуске Windows спросит разрешение на сеть для Apache — нужно нажать **Разрешить**, иначе вкладки не будут обращаться к устройствам.

## Настройка

Параметры в `config.php`, доступ через точечную нотацию.

| Ключ | По умолчанию | Назначение |
| --- | --- | --- |
| `snmp.community` | `public` | SNMP-community принтеров |
| `snmp.timeout` | `500000` | таймаут SNMP, микросекунды |
| `snmp.retries` | `1` | повторы SNMP-запроса |
| `snmp.lock` | `null` | путь к файлу-мьютексу, `null` — системный temp |
| `python.binary` | `python` | имя или путь к интерпретатору Python |
| `python.script` | `scripts/scanpc.py` | путь к Python-хелперу |
| `http.timeout` | `3` | таймаут HTTP к телефонам, секунды |
| `http.attempts` | `2` | сколько раз опросить телефон повторно |

Если Python называется иначе (`python3`), поправьте `python.binary`.

`public` — стандартное значение, его можно коммитить в репозиторий. Свой настоящий community коммитить нельзя: он передаётся открытым текстом и раскроет пароль SNMP на оборудовании в сети.

## Если ничего не находится

**Принтеры пусто** — не совпадает `snmp.community` (у части принтеров он отличается от `public`); SNMP режет брандмауэр Windows (исходящие UDP 161); не загружено расширение `snmp`; принтер в другом сегменте.

**Компьютеры пусто** — недоступен Python (`python --version`) или имя не совпадает с `python.binary`. Сканер ищет только рабочие станции Windows: узел должен отвечать на порт 135 или 445 и иметь разрешимое имя хоста.

**Телефоны не находятся** — определяется только Yealink, телефон должен отвечать на порт 80. Если телефон находится не всегда, увеличьте `http.attempts`: Yealink прекращает отвечать на веб-интерфейс после нескольких запросов подряд.

**Страница грузится несколько секунд** — нет папки `cache` или нет доступа на запись. В ней кэшируется локальный адрес сервера на час; папка создаётся автоматически при первом запуске.

## Структура

```
ScanPPP/
├── index.php              # интерфейс: три вкладки, data-роли для JS
├── api.php                # точка входа API
├── bootstrap.php          # автозагрузка классов, инициализация настроек
├── config.php             # настройки: SNMP, Python, HTTP
├── src/
│   ├── Api.php            # разбор запроса и маршрутизация
│   ├── Config.php         # хранилище настроек
│   ├── Network.php        # проверка IP, MAC, порты, локальный адрес
│   ├── SnmpClient.php     # SNMP с файловым мьютексом
│   ├── Scanner.php        # абстрактный базовый сканер
│   ├── PcScanner.php      # сканер компьютеров
│   ├── PhoneScanner.php   # сканер IP-телефонов Yealink
│   └── PrinterScanner.php # сканер принтеров и прочих SNMP-устройств
├── scripts/scanpc.py      # Python-помощник: ping, порты, имя хоста, MAC
├── assets/css/style.css   # единый стиль вкладок
├── assets/js/app.js       # движок сканирования и отрисовка
└── cache/                 # кэш локального адреса (создаётся при работе)
```

## API

Ответ — JSON: данные об устройстве, `null` если узел не найден, либо объект с ключом `error`.

| Запрос | Назначение |
| --- | --- |
| `api.php?scanner=pc&ip=<ip>` | компьютер |
| `api.php?scanner=phone&ip=<ip>` | IP-телефон |
| `api.php?scanner=printer&action=check&ip=<ip>` | проверка SNMP и признака принтера |
| `api.php?scanner=printer&action=scan&ip=<ip>` | данные о принтере |
| `api.php?scanner=printer&action=device&ip=<ip>` | прочее SNMP-устройство |

## Заметки по реализации

**SNMP-мьютекс.** Расширение `snmp` в Apache с ZTS исполняет запросы в потоках одного процесса, а net-snmp не потокобезопасен — при параллельных обращениях httpd падал. Все SNMP-вызовы сериализуются файловым замком `flock`, путь задаётся ключом `snmp.lock`.

**Опрос телефонов.** Заголовки берутся из `$http_response_header`, а не отдельным запросом `get_headers` — это вдвое сокращает число обращений к устройству. Yealink T21P перестаёт отвечать после нескольких запросов подряд, поэтому каждый путь опрашивается `http.attempts` раз с паузой.

**Локальная подсеть.** Адрес сервера берётся с интерфейса, имеющего шлюз по умолчанию, и кэшируется на час в `cache/primary_ip.txt`. Значение передаётся в страницу как `data-server-ip` и используется для пресета локальной подсети.
